# 暗夜森林·乱斗

一款带 2.5D 纵深的横版过关清版动作游戏原型（参考《三国战纪》《恐龙快打》）。纯 HTML5 Canvas + JavaScript，无任何外部依赖；美术与音效全部由代码程序化生成。

直接用浏览器打开 `index.html`，或部署到任意静态托管（如 GitHub Pages）即可游玩。

## 操作

| 按键 | 功能 |
|---|---|
| 方向键 / WASD | 移动（左右 + 上下纵深） |
| J | 攻击（连击）；长按蓄力 |
| K | 跳跃（空中攻击伤害提升） |
| L | 必杀（体力满时） |
| U | 施放当前魔法 |
| I | 切换魔法 |
| E | 与女巫交谈 / 关闭菜单 |
| 1 / 2 / 3 | 在女巫菜单中学习魔法 |
| M | 静音开关 |
| R / 回车 | 结束后重新开始 |

> 浏览器自动播放限制：音频在第一次按键后启动。

## 系统

- **关卡**：3 波小兵 + 首领（哥布林酋长）。每波锁定画面，清空后出现「GO →」。
- **掉落**：击败敌人散落金币；概率掉落魔法瓶、利剑（攻击 +4）、护甲（防御 +2）。精英与首领必掉。
- **体力 / 必杀**：命中敌人或受伤积累体力，满 100 后按 L 释放全屏必杀「苍蓝剑气」。
- **经验 & 女巫**：击杀获得经验（小兵 10 / 精英 30 / 首领 80）。在波次间找女巫按 E，花费经验学习魔法：
  - 火球术 40 经验，消耗 1 魔法瓶 — 直线穿透火球
  - 冰霜新星 70 经验，消耗 2 魔法瓶 — 冻结周围敌人 3 秒
  - 雷击 100 经验，消耗 3 魔法瓶 — 雷电劈中最多 5 个敌人
- **砍杀熟练度**：近战每命中一个敌人 +1。
  - Lv2（15）旋风斩：连击第 4 击 360° 范围斩
  - Lv3（40）突刺冲锋：前方向 + J
  - Lv4（80）剑气波：长按 J 蓄力后松开
  - Lv5（140）必杀强化：伤害 +50%，金色「天穹剑气」
- **音效**：Web Audio API 实时合成全部音效与循环背景音乐。

## 文件

- `index.html` — 入口
- `game.js` — 游戏逻辑与绘制
- `audio.js` — 程序化音效与音乐
- `test_playwright.js` — 无头浏览器测试脚本（开发用，需 `npm i playwright-core` 与本机 Chrome）
