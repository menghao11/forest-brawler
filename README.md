# 青衣剑客 · 五关乱斗

一款带 2.5D 纵深的横版过关清版动作游戏（参考《三国战纪》《恐龙快打》）。纯 HTML5 Canvas + JavaScript，无任何外部网络依赖；音效与音乐由 Web Audio 实时合成。

- 在线试玩：<https://menghao11.github.io/forest-brawler/>
- 本地：用浏览器打开 `index.html`（或任意静态服务器）即可。

![主角：待机 / 连斩 / 终结技](screenshot_hero.png)

## 操作

| 按键 | 功能 |
|---|---|
| 方向键 / WASD | 移动（左右 + 上下纵深） |
| J | 攻击（连击）；长按蓄力（Lv4 剑气波）；前方向 + J 突刺（Lv3） |
| K | 跳跃（空中 J 为下劈） |
| L | **终结技·万剑归宗**（体力满 100） |
| U | 施放当前魔法（未学会时提示「尚未学习魔法」） |
| I | 切换魔法 |
| E | 与女巫交谈 / 关闭菜单 |
| 女巫菜单 | ←→ 选择系别，↑↓ 选择法术，J 学习；也可鼠标 / 触摸直接点选 |
| M | 静音开关 |
| 回车 / 点击 | 选关、结算、重新开始 |

### 手机 / iPhone 触控

触屏设备自动显示虚拟按键（请横屏；竖屏会提示「请横屏游戏」）。支持多点触控，可边移动边攻击。

| 触控 | 功能 |
|---|---|
| 左侧虚拟摇杆 | 8 方向移动（含纵深） |
| 攻击 / 跳跃 | 同 J / K（长按攻击蓄力） |
| 终结技 | 体力满时发光 |
| 魔法 / 切换 | 同 U / I |
| 女巫 | 靠近女巫时出现；菜单中直接点选法术学习，点「关闭」退出 |
| 音 | 静音开关 |

iOS Safari 可「添加到主屏幕」全屏游玩；首次触摸后启用音频。

## 系统

- **主角**：青衣剑客精灵。待机（6 帧，8fps）、行走（8 帧，12fps，与 200px/s 移速同步；跑步复用行走）、四段普攻 atk1–atk4（各 6 帧，约 18–20fps，第 4 帧剑伸出时判定，收招最后约 1/3 可输入缓冲接下一段；熟练度 2 级起第 5 段为旋风斩）与受击（3 帧）来自新逐帧设定图 `ref/hero_frames_v2.png`，经 `tools/hero_v2_cut.py`（rembg BiRefNet）+ `tools/hero_v2.py`（棋盘格感知清理、补回被误删的灰色剑身、统一比例 / 脚底锚点、按躯干中心平滑水平锚点防抖）打包进 `assets/hero_atlas.png`，HUD 头像取自 idle_01 脸部；其余动作沿用旧图集 `assets/hero_atlas_v1.png`（原 `ref/hero_sheet.png` 切图）并整体色相偏移到新青绿配色：跳、转身、突刺、横斩、升斩、下劈、旋风斩、剑气、闪避、格挡、蓄力、终结技、受击、倒地。切图脚本保证每帧只有一个人物（去除残影 / 斩击光弧 / 相邻帧残片、去灰边），所有帧统一脚底锚点与比例；动画帧率约为旧版 1.6–1.9 倍，攻击可在收招阶段输入缓冲接下一段，帧数少的动作带挤压 / 位移补间，缩放绘制开启平滑。敌人图集同样经过 `tools/clean_atlas.py` 清理（每帧只留主体、去半透明灰边与标签框、剔除残片帧）；第二关大雪人使用专用设定图 `ref/snowboss_sheet.png`，经 `tools/snowboss2.py`（rembg BiRefNet 抠图 + 去灰边 + 统一锚点）切出待机、行走、挥击、砸地、冰锥召唤、投掷、冲击波、死亡帧及冰锥 / 巨雪球特效与 HP 条表情头像，稀疏帧间用补间衔接。
- **场景道具**：灯具与灌木 / 草丛使用 `ref/props_sheet.png` 立绘（`tools/props_cut.py` 用 rembg BiRefNet 抠图并缓存到 `ref/props_cut/`，`tools/props.py` 去灰边、保留地面石块底座、统一底线锚点并预缩放打包为 `assets/props_atlas.png`）。灯具放在走道后方中景，带闪烁的加色光晕与地面光池（火盆火焰另成一层，拉伸摇曳并飘火星）；中景灌木 / 草在走道后方，走道下沿零星草丛参与深度排序；近景层为预先压暗、模糊的大号灌木 / 草（视差 1.25×），玩家走到其后方时自动淡出。每关按主题搭配：暗夜森林（木灯柱 / 石柱吊灯 / 火盆、深绿灌木 / 蕨 / 蓝花丛）、雪岭（蓝水晶灯、雪灌木、霜草）、火山（石火盆、枯黄草、零星红叶丛）、溪谷（木灯柱 / 石柱灯、花丛 / 黄绿灌木、芦苇、蕨、花草）、古堡（哥特红双灯 / 石柱壁灯、红叶丛）。
- **关卡节奏**：每波敌人分批增援入场（场上剩 ≤1 只时下一批冲入）。不闪避的自动脚本实测：第 1–4 关约 5.2–6.0 分钟，第 5 关约 7.3 分钟。
- **掉落**：金币、魔法瓶、利剑（攻击 +）、护甲（防御 +）；精英与首领必掉。
- **体力 / 终结技**：命中或受伤积累体力，满后按 L 释放「万剑归宗」——飞剑雨锁定屏内每个敌人。
- **魔法**：击杀获得经验，在女巫处学习火 / 冰 / 雷三系共 16 个法术（同系按顺序），施放消耗魔法瓶。特效来自 `ref/magic_sheet.png`。
- **砍杀熟练度**：近战命中累积，30 / 120 / 300 / 600 分别解锁旋风斩、突刺冲锋、剑气波、终结技强化。
- **音效**：Web Audio API 合成全部音效与背景音乐。

## 文件

- `stages.js` — 五关配置（背景、波次、危害；替换背景改这里）

- `audio.js` — 程序化音效与音乐
- `touch.js` — 移动端触控
- `assets/` — 精灵图集（主角、哥布林、大哥布林、蝙蝠、吸血伯爵、法术特效）与各关远景
- `ref/` — 原始美术参考图
- `docs/关卡设计.md` — 关卡设计文档
- `screenshot_stage2_boss.png` — 第二关大雪人首领战截图（冰锥召唤）
- `screenshot_snowboss_check.png` — 大雪人切图帧检查表（脚底基线对齐、特效与表情头像）
- `screenshot_props_s1.png` … `screenshot_props_s5.png` — 五关场景道具（灯具光晕 / 灌木 / 草丛）截图
