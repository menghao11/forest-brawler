# 青衣剑客 · 五关乱斗

一款带 2.5D 纵深的横版过关清版动作游戏（参考《三国战纪》《恐龙快打》）。纯 HTML5 Canvas + JavaScript，无任何外部网络依赖；音效与音乐由 Web Audio 实时合成。

- 在线试玩：<https://menghao11.github.io/forest-brawler/>
- 本地：用浏览器打开 `index.html`（或任意静态服务器）即可。

![主角：待机 / 连斩 / 终结技](screenshot_hero.png)

## 操作

| 按键 | 功能 |
|---|---|
| 方向键 / WASD | 移动（左右 + 上下纵深） |
| J | 攻击（连击）；长按蓄力（Lv4 剑气波）；前方向 + J 突刺（Lv3） |
| K | 跳跃（空中 J 为下劈） |
| L | **终结技·万剑归宗**（体力满 100） |
| U | 施放当前魔法（未学会时提示「尚未学习魔法」） |
| I | 切换魔法 |
| E | 与女巫交谈 / 关闭菜单 |
| 女巫菜单 | ←→ 选择系别，↑↓ 选择法术，J 学习；也可鼠标 / 触摸直接点选 |
| M | 静音开关 |
| 回车 / 点击 | 选关、结算、重新开始 |

### 手机 / iPhone 触控

触屏设备自动显示虚拟按键（请横屏；竖屏会提示「请横屏游戏」）。支持多点触控，可边移动边攻击。

| 触控 | 功能 |
|---|---|
| 左侧虚拟摇杆 | 8 方向移动（含纵深） |
| 攻击 / 跳跃 | 同 J / K（长按攻击蓄力） |
| 终结技 | 体力满时发光 |
| 魔法 / 切换 | 同 U / I |
| 女巫 | 靠近女巫时出现；菜单中直接点选法术学习，点「关闭」退出 |
| 音 | 静音开关 |

iOS Safari 可「添加到主屏幕」全屏游玩；首次触摸后启用音频。

## 战役

| 关 | 名称 | 首领 | 特色 |
|---|---|---|---|
| 1 | 暗夜森林 | 哥布林酋长 | 入门，哥布林刀盾 / 长矛兵 |
| 2 | 雪岭寒关 | 大雪人 | 小雪人 / 木棒雪人 / 雪球雪人 / 冰甲雪人（`ref/snowman_sheet.png` 精灵）；锤击、冰雪冲击波、投掷冰石、滚动巨雪球、召唤小雪人；火弱冰抗 |
| 3 | 熔岩火山 | 焰魔王·赤烎 | 地裂喷发、陨石、熔岩桥；掉落烈炎剑 |
| 4 | 溪谷森林 | 哥布林大王 | 弓手、跳斩手、木桥、浅溪，战旗 |
| 5 | 黑夜古堡（FINAL） | 吸血伯爵 | 蝙蝠 / 巨蝠、残影大王重战、王座大厅、血月；通关解锁 NG+ |

第 1–4 关 18 波、第 5 关 16 波，再加多阶段首领，含精英波与每关 4 处女巫休息点（真人每关约 8–12 分钟）。进度、最佳时间与成长自动保存在浏览器（localStorage）；在女巫处学会的法术立即存档。详细设计见 [`docs/关卡设计.md`](docs/关卡设计.md)。

## 系统

- **主角**：青衣剑客精灵（`ref/hero_sheet.png` 切图打包为 `assets/hero_atlas.png`），动画：待机、走、跑、跳、转身、五段连斩、突刺、横斩、升斩、下劈、旋风斩、剑气、闪避、格挡、蓄力、终结技、受击、倒地。切图脚本保证每帧只有一个人物（去除残影 / 斩击光弧 / 相邻帧残片、去灰边），所有帧统一脚底锚点与比例；动画帧率约为旧版 1.6–1.9 倍，攻击可在收招阶段输入缓冲接下一段，帧数少的动作带挤压 / 位移补间，缩放绘制开启平滑。
- **掉落**：金币、魔法瓶、利剑（攻击 +）、护甲（防御 +）；精英与首领必掉。
- **体力 / 终结技**：命中或受伤积累体力，满后按 L 释放「万剑归宗」——飞剑雨锁定屏内每个敌人。
- **魔法**：击杀获得经验，在女巫处学习火 / 冰 / 雷三系共 16 个法术（同系按顺序），施放消耗魔法瓶。特效来自 `ref/magic_sheet.png`。
- **砍杀熟练度**：近战命中累积，30 / 120 / 300 / 600 分别解锁旋风斩、突刺冲锋、剑气波、终结技强化。
- **音效**：Web Audio API 合成全部音效与背景音乐。

- `game.js` — 游戏逻辑、敌人 / 首领 / 法术数据、绘制
- `audio.js` — 程序化音效与音乐
- `touch.js` — 移动端触控
- `assets/` — 精灵图集（主角、哥布林、大哥布林、蝙蝠、吸血伯爵、法术特效）与各关远景
- `ref/` — 原始美术参考图
- `docs/关卡设计.md` — 关卡设计文档
- `screenshot_stage2_boss.png` — 第二关大雪人首领战截图
- `screenshot_anim_check.png` — 主角行走 + 连斩逐帧接触表（检查无重影）
- `test_playwright.js` / `test_mobile.js` — 无头浏览器测试（开发用，需 `npm i playwright-core` 与本机 Chrome）
